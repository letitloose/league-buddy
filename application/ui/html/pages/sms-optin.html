SMS Opt-In

The real phone-verification and reminder-delivery opt-in flow on a player's Notification Preferences page, start to finish. Click any screenshot to view it full-size.

For a carrier/Twilio resubmission, attach the screenshot files directly — this page is a reference walkthrough, not the proof itself. The first six cover the required opt-in flow; the seventh (reversibility) is supporting evidence, not a strict requirement.

1. Before verifying: optional-language, consent text, and an unchecked checkbox

Shows: branding, the explicit "Text notifications are optional" statement, the full SMS-program consent text (STOP/HELP and message-rate disclosure included), and the checkbox unchecked by default.

2. Requesting a code without opting in: a non-mandatory validation message

Shows: the checkbox is required only to request a code (an SMS obviously can't be sent without consent to be texted at all), but the message itself reads as optional — "Check this box only if you want to receive text notifications" — not as if SMS were required to use the site.

3. After opting in: verification code sent

Shows: the real authenticated Blame the Ball flow — checking the box and submitting actually texts a one-time code to the entered number, with the code-entry field ready.

4. Phone number verified

Shows: phone verification completing, unlocking Text as a delivery option below.

5. Reminder Delivery: one program, separately opt-out-able by notification type

Shows: RSVP reminders and captain's messages as two independent rows, each with its own Email and Text checkbox — proving a player can enable text for one notification type while declining it for another, rather than one opt-in covering everything bundled together.

6. Saved: the final Save action and its confirmation

Shows: clicking Save actually persists the chosen per-notification Email/Text selections, with a confirmation message and the site footer's Privacy Policy/Terms & Conditions links visible.

7. Reversible at any time: Remove Phone Number and Opt Out of SMS Program

Shows: consent isn't a one-way door. A player can revoke SMS program consent (independent of their phone number) or remove their phone number entirely (independent of that consent) at any time from the same page, on top of the standard carrier-level STOP reply.
